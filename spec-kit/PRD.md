# FLATTEN Product Requirements Document

## 1. 제품 개요

- 서비스명: FLATTEN
- 서비스 설명: 팬덤 데이터를 기반으로 브랜드 마케팅, 펀딩, 라이브 캠페인을 지원하는 플랫폼
- 핵심 가치: 팬덤과 브랜드를 데이터로 연결하고 캠페인 참여 경험을 제공

## 2. 주요 사용자 경험

### Home

- 브랜드 메시지를 전달하는 Hero 배너
- 브랜드 스토리 및 핵심 가치 소개
- 주요 지표와 수치 표시
- 추천 캠페인 슬라이더
- 주요 행동을 유도하는 CTA 버튼

### All Campaigns

- 전체 캠페인 목록 제공
- 카테고리 필터링
- 진행 상태 필터링
- 정렬 기능
- 검색 기능
- 반응형 카드 그리드 뷰

## 3. 공통 UI 요구사항

### Header / GNV

- 모든 페이지에서 동일한 글로벌 헤더 사용
- FLATTEN 로고 링크 제공
- 데스크톱 네비게이션 제공
- 모바일 햄버거 메뉴 및 드로어 제공
- 로그인/회원가입 및 검색 등 사용자 액션 영역 제공
- 모바일 메뉴의 열림 상태를 `aria-expanded`로 전달

### Footer

- 어두운 톤의 공통 푸터 사용
- 주요 네비게이션 링크 제공
- 이용약관, 개인정보처리방침, 사업자 정보 등 서비스 정보 제공
- 공식 SNS 및 패밀리 사이트 채널 연결

## 4. 캠페인 UI 요구사항

- 캠페인 카드에 썸네일 이미지 표시
- 진행 상태 및 달성률 배지 표시
- 캠페인 목표 달성률 Progress Bar 제공
- 추천 캠페인은 터치 가능한 슬라이더로 제공
- 데스크톱과 모바일에서 반응형으로 동작

## 5. 디자인 요구사항

- Pretendard 계열 폰트 우선 사용
- 공통 색상, 여백, 폰트, 반경 값은 디자인 토큰으로 관리
- 클래스명은 BEM 규칙을 우선 적용
- 공통 컨테이너를 사용해 콘텐츠 폭과 중앙 정렬을 일관되게 유지
- 페이지별 스타일은 전역/레이아웃/페이지 스코프로 분리
- 브랜드 비주얼은 고대비 타이포그래피와 영상·이미지 중심으로 구성

## 6. 접근성 및 반응형 요구사항

- 키보드로 모든 주요 인터랙션 조작 가능
- `:focus-visible` 기반 포커스 링 제공
- 모바일 드로어, 아코디언, 캐러셀의 상태를 ARIA 속성으로 전달
- 스크린 리더용 숨김 텍스트 제공
- `prefers-reduced-motion: reduce` 환경에서 애니메이션과 전환 효과 축소
- 모바일, 태블릿, 데스크톱 브레이크포인트 대응

## 7. 기술 및 운영 요구사항

- 정적 HTML/CSS/JavaScript 기반 페이지 구조와 호환
- 전역 스타일, 레이아웃 스타일, 페이지 스타일을 분리
- 서드파티 슬라이더는 Swiper 기반으로 구성 가능
- 개발 파일명은 해시 없는 의미 기반 파일명을 사용
- 유지보수를 위해 컴포넌트와 공통 모듈을 단일 위치에서 관리

## 8. 향후 개발 우선순위

1. CSS 디렉터리와 파일 구조 표준화
2. 디자인 토큰 파일 구축
3. BEM 네이밍 및 JavaScript 훅 정리
4. ARIA, 키보드 포커스, 스킵 링크 등 접근성 보완
5. 모션 감축 및 반응형 동작 점검
