[로그인/회원가입 기능 만들기]
현재 사이트는 로그인 기능이 없어.
회원가입 기능과 더불어서 로그인 기능을 구현해.
회원가입 정보는 이름, 아이디, 비밀번호, 이메일까지만 받아서 중복 체크 등 기본 기능을 구현해.
상태 표시해줘. ("예 : 사용자님 환영합니다")
로그인 시 변경될 변화는 현재의 공지사항의 글쓰기, 수정, 삭제 기능을 admin에게만 준다는 것이야.
관리자 계정은 수동으로 등록해줘.

이름 : 관리자
아이디 : admin
비밀번호 : 1111
이메일 : admin.com.@company.co.kr

- 유의사항 : 
로그인 시 로그아웃 버튼으로 변경하여 활성한다.
그리고 로그인 버튼 클릭 시 로그인 화면으로 가고 회원가입은 그 페이지 하단에 위치하게 해.

- 디자인 : 
공지사항 화면을 기준하여 디자인해.

- 데이터처리 : 파이어베이스로 구현.


[수정구현]
1. 로그인 페이지와 회원가입 페이지 분리하고 로그인 페이지 하단에 링크로 회원가입 페이지로 이동할 수 있게 수정해.
2. 회원가입 시 입력되는 사용자 정보는 아래의 예와 같은 필드로 입력되는지 확인하고 아니면 수정해.
단, 일반회원은 role값이 'user'이고 관리자는 'admin'이다.

예)
createdAt
"2026-11-06T05:39:31.255Z"
(string)


email
"admin@admin.com"
(string)


name
"관리자님"
(string)


role
"admin"
(string)


username
"admin2"


[추가변경요청]
- 현재 상단과 하단의 공통 모듈이 각 페이지에 하드코딩되어 있어.
이 부분을 하나로 만들고 모듈화하여 다른 페이지별로 관리하지 말고 한곳에서 제어하도록 수정해.
