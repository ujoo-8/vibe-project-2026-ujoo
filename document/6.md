## 📄 [문서 1] 전체 PRD (Product Requirements Document)

### 1. 제품 개요 (Product Overview)
* **제품명**: Flatten (플래튼) 브랜드 & 팬덤 데이터 플랫폼 웹사이트
* **벤치마킹 대상**: `https://www.flatten.co.kr`
* **목적**: 팬덤 데이터 기반의 엔터테인먼트/브랜드 마케팅 에이전시 및 플랫폼 정체성을 선명하게 전달하고, 캠페인 성과와 비전을 하이엔드 인터랙티브 웹 UX로 제공.

### 2. 브랜드 및 비주얼 정체성 (Visual Identity)
* **디자인 톤앤매너**:
  * Dark/Black 모노톤 기반의 고대비(High-contrast) 네오-브루탈리즘 및 미니멀리즘 조화.
  * 서체 중심(Typography-driven) 인터페이스: 메인 대형 키네틱 타이포그래피, 가독성이 높은 샌세리프 서체.
  * 역동적인 그리드 전환 및 호버 마이크로 인터랙션.
* **컬러 파렛트**:
  * Background: `#0e0e0e` / `#000000` (Dark Base), `#ffffff` (White Card/Modal)
  * Text: Light Gray (`#f3f3f3`), Pure White (`#ffffff`), Muted Gray (`#888888`)
  * Accent: Neo-Neon Red/Pink 또는 Vivid Cyan (포인트 커서 및 링크 하이라이트)

### 3. 정보 설계 및 핵심 섹션 (Information Architecture)
1. **GNB / Header Navigation**:
   * 로고, 서브 메뉴(ALL CAMPAIGNS, ABOUT, CAREER 등), 언어 선택(KO/EN), 문의하기(CONTACT) CTA 버튼.
   * 스크롤 시 고정(Sticky Header) 또는 모션 숨김/노출.
2. **Hero Section (메인 비주얼)**:
   * "Empowering fandom & Brand through data" 슬로건 강조.
   * 대형 비디오/이미지 루프 또는 인터랙티브 canvas/SVGs.
3. **Core Services & Capabilities (주요 역량)**:
   * 데이터 분석, 캠페인 기획, IP 비즈니스 확장을 시각화한 수평/수직 카드 아코디언.
4. **All Campaigns (프로젝트/캠페인 쇼케이스)**:
   * 필터링 가능한 그리드/카드리스트 레이아웃.
   * 호버 시 미디어 스케일 업, 오버레이 타이틀 노출, 클라우드 비디오 재생.
5. **Data & Metrics Showcase (성과 지표)**:
   * 카운트업 인터랙션 및 카드를 활용한 정량적 데이터 모듈.
6. **Footer / Contact**:
   * 하단 대형 슬로건, 뉴스레터 구독/문의 폼, SNS 링크, 카피라이트.

## 📄 [문서 2] 프론트엔드 개발용 PRD (Frontend-Focused PRD)

### 1. 기술 스택 및 아키텍처 (Tech Stack & Architecture)
* **Core**: React / Next.js (또는 HTML5 + Modern Vanilla JS / Vite)
* **Styling**: Tailwind CSS (권장) 또는 Vanilla CSS Modules (CSS Variables 기반)
* **Animation Library**: GSAP (ScrollTrigger), Framer Motion, Lenis (Smooth Scroll)
* **Icons**: Lucide Icons 또는 SVG Inline Injection

### 2. 디바이스 반응형 브레이크포인트 (Responsive Breakpoints)
* **Desktop Large**: `>= 1440px` (Max-width 1600px 컨테이너 적용)
* **Desktop / Laptop**: `1024px ~ 1439px` (4열/3열 그리드)
* **Tablet**: `768px ~ 1023px` (2열 그리드, 햄버거 메뉴 전환)
* **Mobile**: `<= 767px` (1열 스택, 아코디언 컴포넌트 터치 최적화)

### 3. 주요 UI 컴포넌트 요구사항

#### A. 스무스 스크롤 & 스크롤 트리거 (Smooth Scroll System)
* **기능**: Lenis.js 기반의 자연스러운 가상 관성 스크롤 구현.
* **동작**: 스크롤 위치에 따라 파라독스 효과 및 CSS `--scroll-y` 변수 동기화.

#### B. 캠페인 호버 카드 (Campaign Card Micro-interaction)
* **구조**: `image/video container`, `badge`, `title`, `category`.
* **동작**: 
  * Mouse enter: 이미지 Scale(1.05) & Brightness 조절, 커서 커스텀 텍스트 ("VIEW") 바인딩.
  * Video Lazy Loading: 호버 시 데이터 절약을 위해 `<video>` 재생 시작.

#### C. 아코디언 & 슬라이딩 Drawer (Expandable Content Module)
* **구조**: 상단 헤더 영역 클릭 시 숨겨진 세부 데이터가 펼쳐지는 토글 구조.
* **동작**: Smooth height transition (`max-height` or GSAP `flip`).
* **그라데이션 페이드**: 텍스트 축소 상태일 때 하단 `linear-gradient(to bottom, transparent, #0e0e0e)` 오버레이.

## 📄 [문서 3] 실행용 PRD 요약 문서 (Execution PRD Summary)

### 1. 개발 우선순위 (Roadmap & Milestones)

| 단계 | 작업 영역 | 주요 결과물 | 검증 기준 |
|---|---|---|---|
| **Phase 1** | 글로벌 레이아웃 & 테마 설정 | CSS 변수 설정, 스무스 스크롤, GNB/Footer | 스크롤 프레임 drop 없음 (60fps) |
| **Phase 2** | Hero 섹션 & 대형 타이포 | 반응형 타이포 스케일링, 대각선/카셀 인터랙션 | 디바이스별 깨짐 현상 제로 |
| **Phase 3** | 캠페인 그리드 & 필터링 | 캠페인 카드 리스트, 호버 이펙트, 모달 | 필터 전환 시 자연스러운 애니메이션 |
| **Phase 4** | 데이터 지표 & 아코디언 | 카운터 애니메이션, 아코디언 토글, 폼 UI | 터치 및 키보드 접근성 확보 |
| **Phase 5** | 통합 최적화 & 바이브 테스트 | AI 에이전트 연동, QA, 반응형 세부 조정 | Lighthouse Performance score 90+ |

### 2. 핵심 구현 체크리스트 (Do's & Don'ts)
* **Do**:
  * 모든 색상, 간격, 애니메이션 속도는 CSS Variable로 일원화할 것.
  * 스크롤 이벤트 성능을 위해 `requestAnimationFrame` 및 Throttling 적용.
  * 반응형 폰트 단위로 `clamp()` 적극 활용.
* **Don't**:
  * DOM을 직접 변경하는 과도한 Heavy Library 지양.
  * 인라인 스타일링 배제 (AI 작성 시 클린 코드 유지).

## 📄 [문서 4] 개발용 AI Agent MD 파일 (`.cursorrules` / `AI_AGENT_DEV.md`)

```markdown
# AI Agent Directives: Senior Frontend Engineer for Flatten Vibe Coding

You are an expert Senior Frontend Engineer specializing in high-end UI design systems, micro-interactions, and Vibe Coding workflows. Your goal is to construct the Flatten-like brand platform seamlessly.

## 1. Coding Standards & Principles
- **Language**: Modern JavaScript (ES6+) or TypeScript.
- **Styling**: Modern CSS3 using custom properties OR Tailwind CSS. Do not use random inline styles.
- **Performance**: Ensure smooth 60fps animations. Prefer `transform` and `opacity` for CSS transitions over layout-triggering properties (`width`, `height`, `margin`).
- **Structure**: Clean modular structure. Component logic must be isolated and self-contained.

## 2. UI/UX Specific Rules
- **Color Theme**: Maintain a dark-mode-first mindset (`#0e0e0e` background).
- **Typography**: Apply `clamp()` for responsive typography scaling across devices.
- **Interactions**:
  - Implement smooth cursor interaction wrappers if requested.
  - Cards must feature smooth transform transitions (`transition: transform 0.4s cubic-bezier(0.16, 1, 0.3, 1)`).

## 3. Vibe Coding Workflow
- Produce production-ready, clean, well-commented code.
- Always check responsive behavior at 375px (Mobile), 768px (Tablet), and 1440px (Desktop).
- When generating code, wrap it cleanly in standard Markdown blocks without omitting critical styles.
```

# AI Agent Role: UI/UX & Design System Architect

## 1. Persona & Goal
You are a Lead UI/UX Designer specializing in luxury agency digital branding and dark-mode web experiences (referencing Flatten.co.kr). You define design tokens, visual hierarchies, and micro-interaction specifications for the development team.

## 2. Design System Tokens

### A. Color Variables
- `--bg-primary`: `#0e0e0e`
- `--bg-secondary`: `#181818`
- `--text-primary`: `#ffffff`
- `--text-secondary`: `#a0a0a0`
- `--accent-color`: `#ff2a5f`

### B. Typography Scale
- `--font-hero`: `clamp(3rem, 8vw, 7.5rem)` / Line-height: 1.05 / Tracking: -0.03em
- `--font-h1`: `clamp(2rem, 5vw, 4rem)` / Line-height: 1.1 / Tracking: -0.02em
- `--font-body`: `clamp(0.95rem, 1.2vw, 1.125rem)` / Line-height: 1.6

### C. Motion & Curves
- Fast Ease Out: `cubic-bezier(0.25, 1, 0.5, 1)` (Duration: 0.3s)
- Smooth Hover: `cubic-bezier(0.16, 1, 0.3, 1)` (Duration: 0.5s)

## 3. Interaction Design Mandate
- **Cursor Effects**: Custom floating pointer with dynamic blend modes (`mix-blend-mode: difference`).
- **Visual Rhythm**: High contrast between massive hero headers and neat, well-padded grid cards.
