## 3. 사용자 요구사항 (확정)

### 3.1 레이아웃 규칙 (사이트 디자인은 동일, 내부 레이아웃은 다름)
1. **겉박스 > 속박스 > 파티션 박스** 순의 단순화된 박스 구조.
2. 겉박스 전체 구조: `header + (main > section) + footer`
3. 속박스
   - `max-width` 적용 + 중앙 정렬
   - 사이트에 max-width가 없으면 **1920px** 설정
   - 클래스명은 **`.inner-box`로 일원화**
4. 파티션 박스
   - 일반적으로 **flex** 적용
   - 줄바꿈이 필요한 내용에 따라 **flex-wrap** 적용
   - **Grid로 만들지 않는다.** (내용 박스 내부에서 필요할 때만 grid 허용)

### 3.2 추출·반영 대상
사이트의 ① 박스 관련(크기·패딩·마진) ② 글자 관련 ③ 색상 관련 규칙을 추출해 `AGENTS.md`에 추가·수정.

## 4. 추출 데이터 — flatten.co.kr (FLATTEN.zip 분석 결과)

원본 파일: `base / header / footer / home / all_campaigns` CSS(해시 파일명), `swiper-bundle.min.css`(라이브러리, 분석 제외), 메인 HTML 1개. (원본은 세션 임시 폴더에 풀어둠. 새 세션이면 사용자에게 재첨부 요청)

### 4.1 구조 관찰
- 공통 헤더 2종: `#site-header`(데스크톱) / `#mobile-header`(≤1024px). 둘 다 `header` 태그, sticky.
- 페이지 래퍼 `#flatten_home` > `main` > `section`(cover, why-flatten, our-solutions, campaigns, newsroom). 푸터 `#site-footer`.
- 사이트 CSS는 **ID 선택자, 깊은 중첩, `!important`** 사용 → 일반 규약(V6.1)과 충돌. 신규 구현은 **일반 규약 우선**(클래스·BEM), 시각 값만 따라간다.
- 섹션 내부 폭은 **`width:75%`로 중앙 정렬**(1920 기준 1440px 상당), 모바일은 100% + 좌우 16px 패딩.
- 섹션별 명암 교대(JS로 헤더 `.dark` 전환): cover=밝음 / why-flatten=어두움 / our-solutions=어두움 / campaigns=밝음 / newsroom=어두움.
- 브레이크포인트는 **`max-width:1024px` 단 1개**(데스크톱/모바일 2단계).
- 스무스 스크롤 라이브러리 Lenis, 스크롤 진입 시 `fadeUp` 애니메이션 사용.
- 브랜드 컬러 없음. **흑·백·회색 모노톤** 사이트.

### 4.2 크기 단위 방식
- 데스크톱: 디자인 1920px 기준 → `clamp(최소px, N/1920*100vw, 9999px)`
- 모바일: 디자인 375px 기준 → `clamp(최소px, N/375*100vw, 9999px)`
- 즉 **px값 / 기준폭 × 100vw** 로 비례 확대하되 최소값을 보장한다.
